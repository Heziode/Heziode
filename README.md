# Quentin Dauprat

Software engineer building agentic AI systems with the rigor of safety-critical software. PhD in computer science (static analysis of Ada). Based in France.

## What I build

- **Agentic systems.** LLM agents wired through MCP, with cost and quality evaluation, from a fuzzy need to production. My own site [foe.tools](https://foe.tools) (about 70,000 visitors a day) runs its support on them.
- **Verified software.** Open-source Ada/SPARK libraries, with absence of runtime errors proven by GNATprove, published under [Adarium Labs](https://github.com/adarium-labs).
- **Developer tooling.** Rust, TypeScript and Ada tools for people who care about correctness.
